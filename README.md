# 行事予定管理アプリ

学校の年間の行事予定を入力・管理し、月間予定表・年間予定表(教員用・家庭用)を作るアプリです。
給食の日数、授業時数の集計、学級ごとの実績の管理もできます。以前 Excel のマクロで行っていた作業を置き換えるものです。

## 使い方

1. 校務共有サーバーにある `index.html` を、**Chrome または Edge** で開きます。
2. 行事予定のデータファイル(`.json`。以前のものは `.dat`)を開きます。
   - 初めて使うとき:「名前を付けて保存」で、データファイルの保存場所と名前を決めます(`index.html` と同じフォルダがおすすめです)。
   - 2回目から:前回のファイルが自動で開きます。開かないときは「開く」でファイルを選びます。
3. 入力や変更をするときは、「🔒 編集する」を押して編集パスワードを入れ、編集モードにします。
   - 同時に2人が編集しないよう、編集中はほかの先生の画面に表示が出ます。終わったら「編集を終える」を押してください。
4. 画面上のタブで作業を切り替えます。

| タブ | できること |
|---|---|
| 予定入力 | 日ごとの行事・会議・給食・①〜⑥の授業などを入力する |
| 月間予定表 / 年間予定表 | 教員用・家庭用の予定表を確認し、Excel に出力する |
| 給食 | 給食の実施日数・喫食数を確認する |
| 時数・集計 | 授業時数・授業日数・授業週数を集計する |
| 実績 | 学級ごとの時間割を入れて、教科ごとの時数を集計する |
| 設定 | 学校名・年度・祝日・編集パスワード・自動バックアップなど |

詳しい使い方は、アプリ内の「使い方 / マニュアル」にあります。

## データの保存場所

- 行事予定は、開いている **データファイル(`.json`)**(校務共有サーバー上)に自動で上書き保存されます。画面の上に、今開いているファイル名が表示されます。
- データファイルの中身は JSON という形式の文字データで、メモ帳などでも開けます(直接書き換えないでください)。以前の `.dat` ファイルも中身は同じで、そのまま開いて使えます。`.json` にそろえたいときは、開いたあと「名前を付けて保存」で `.json` として保存し直してください。
- 実際の行事予定は校内でだけ扱います。**インターネットやクラウド(Googleドライブ等)には置かないでください。**

## バックアップと復元

- **自動バックアップ**:「設定」タブの「自動バックアップ」でフォルダを選ぶと、`行事予定_バックアップ_日付_時刻.json` が自動で保存されます(保存のたび/30分おき/1日1回から選べます)。
- **手動のバックアップ**:「名前を付けて保存」で、別の名前(例:`行事予定_バックアップ_2026-09-27.json`)を付けて保存します。
- **復元**:「開く」でバックアップのファイル(`.json`。以前のものは `.dat`)を選びます。そのあと「名前を付けて保存」で、いつものファイル名で保存し直してください。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 入力できない | 編集モードになっているか確認してください。編集パスワードが分からないときは担当の先生に聞いてください。 |
| 「別の場所でこのファイルが編集中です」と出る | ほかの先生が編集中です。終わるのを待ってください。 |
| 前回のファイルが開かない | 「開く」でデータファイル(`.json` または `.dat`)を選んでください。 |
| データがおかしくなった | 「開く」で自動バックアップのファイル を選んで確認し、よければ「名前を付けて保存」でいつものファイル名に保存し直してください。 |
| Chrome・Edge 以外で開いている | 自動保存が使えません。Chrome か Edge で開き直してください。 |

- `行事予定管理アプリ_Phase1.html` は、古いアドレスから `index.html` へ移動させるためだけのページです。`サンプルデータ_1年分.json` は架空のサンプルデータです。
